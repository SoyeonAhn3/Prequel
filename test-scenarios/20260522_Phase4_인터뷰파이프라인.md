### TC-001 [정상] 👤 수동 — 인터뷰 시작 → 첫 질문 수신 + 3컬럼 UI 표시

**사전조건**: 인터뷰 미시작 프로젝트가 프로젝트 목록에 존재
**실행 단계**:
1. `/projects` 페이지에서 해당 프로젝트 이름 클릭
2. 로딩 화면("인터뷰를 준비하고 있습니다...") 확인
3. 3컬럼 UI가 완전히 로딩될 때까지 대기 (2~10초)
**입력값**: 없음 (자동 시작)
**예상 결과**:
- 로딩 중 "P" 로고가 pulse 애니메이션으로 표시된다
- 로딩 완료 후 3컬럼 레이아웃이 표시된다:
  - **왼쪽 레일**: "Prequel" + 초록 상태 점("인터뷰 진행 중"), 프로젝트명, "PHASE 1 of 3" + 미니 프로그레스바, 진행률 카드(1/10), STEP 1이 active(accent 맥동), 나머지 STEP이 pending(회색 번호)
  - **중앙**: 상단 빵부스러기 "STEP 01 · [스텝명] · 1번째 질문", AI 첫 질문이 accent 테두리 질문 카드로 표시, 하단 퀵 액션 칩 3개, 입력 영역, 통계 바(0:00부터 카운트)
  - **오른쪽**: "수집된 정보" 헤더, "문서 미리보기" 버튼, "자동 저장됨" 표시
- 상단 헤더에 프로젝트명이 표시된다
**확인 방법**: 3컬럼 모두 렌더링 확인. Network 탭에서 `POST /api/interview/start` → 200 확인.

**사전조건**: 인터뷰 진행 중, AI가 마크다운 형식으로 응답하는 단계 (STEP 3 이후 권장)
**실행 단계**:
1. AI 질문 카드의 텍스트에 마크다운 서식이 적용되어 렌더링되는지 확인
2. 이전 대화(dimmed) 영역의 AI 메시지에도 마크다운이 적용되는지 확인
3. 다양한 서식 확인: **볼드**, 리스트(bullet/번호), 테이블, 코드(`inline`), 구분선
**입력값**: 없음 (AI 응답 관찰)
**예상 결과**:
- **볼드** 텍스트가 `font-semibold`로 강조 표시된다
- bullet(•) 리스트가 들여쓰기 + disc 마커로 표시된다
- 번호 리스트가 decimal 마커로 표시된다
- 테이블이 있을 경우 가로 스크롤 가능한 `<table>`로 렌더링된다 (헤더 회색 배경)
- 인라인 코드가 `bg-surface-alt rounded` 스타일의 `<code>` 태그로 표시된다
- 마크다운 원문(`**`, `- `, `|---|`) 이 텍스트로 노출되지 않는다
- 질문 카드와 이전 대화 모두에서 동일하게 렌더링된다
**확인 방법**: AI 응답에서 서식 렌더링 육안 확인. 마크다운 원문 노출 없음 확인.
