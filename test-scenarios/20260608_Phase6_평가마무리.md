# 테스트 시나리오 — Phase 6 평가·마무리

- **생성일**: 2026-06-08
- **대상 Phase**: Phase 6 (Evaluation & Finalization)
- **구현 기능**: 설계 후(또는 건너뛴 후) 4단계 마무리 플로우 — 정직한 평가(evaluate) → 완료 조건(done) → 빈틈 점검(gap) → 착수 체크리스트(checklist) → 완료 화면. 체크리스트 완료 시 doc v3 생성 + 프로젝트 `completed` 처리. 설계→마무리 전환 버그 수정 포함.
- **전제조건**:
  - 백엔드 http://127.0.0.1:8000 · 프론트엔드 http://localhost:5176 실행 중
  - `DEV_BYPASS_AUTH=true` (로그인 없이 접근)
  - 테스트 프로젝트: **"등기부등본 AI 해석기"** (`eaab0bfb…`, status=`evaluating`, 평가 단계 초기화 완료 — finalize_session 없음)
