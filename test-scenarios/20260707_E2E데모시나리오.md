# 테스트 시나리오 — Phase 9 E2E 데모 시나리오

- **생성일**: 2026-07-07
- **대상 Phase**: Phase 9 (통합·마감·배포) — Deliverable #6
- **구현 기능**: MVP-1 전체 흐름(랜딩 → 로그인 → 프로젝트 생성 → 인터뷰 → 문서 → 관리자)을 실제 사용자처럼 처음부터 끝까지 한 바퀴 검증
- **전제조건 (공통)**:
  - 백엔드 실행 중(`backend/`에서 `uvicorn app.main:app --port 8000`), 프론트 실행 중(Vite `http://localhost:5176`, `/api` 프록시)
  - 루트 `.env`에 **유효한** `ANTHROPIC_API_KEY` + Supabase 키(URL/anon/service) 설정
  - **로그인(TC-002)을 실제로 검증하려면** `DEV_BYPASS_AUTH=false`로 두고 백엔드 재시작 필요(구글 OAuth 리다이렉트 URL도 Supabase에 등록돼 있어야 함). 나머지 흐름만 볼 거면 `DEV_BYPASS_AUTH=true`로 로그인 단계 생략 가능
  - 브라우저 콘솔(F12)을 열어둔 채 진행하여 에러 발생 여부를 함께 관찰

> ⚠️ **Phase 9 문서와의 차이(실측 반영)**: 인터뷰는 **11단계(N/11)**이며 문서상 "10개 질문"은 마케팅/목업 문구. 프로젝트 **유형 자동감지는 인터뷰 도중** 이뤄짐(생성 단계엔 유형 입력 없음). **공지 작성은 `/admin`이 아니라 `/notices`**(관리자 모드 토글). 인터뷰 완료 시 별도 "AI 문서 생성"은 없고 세션 데이터로 **실시간 조립**됨. Mermaid 다이어그램은 스코프 제외.

### TC-003 [정상] 👤 수동 — 새 프로젝트 생성(2단계 모달: 한국어 → 이름/설명)

**실행 단계**:
1. `새 프로젝트`(＋) 버튼을 클릭한다.
2. (1단계 언어) `한국어` 카드를 선택하고 `다음`을 클릭한다.

**입력값**: 이름 = `사내 도서 추천 봇`, 설명 = `직원들이 사내 도서를 추천/검색하는 웹앱`

### TC-004 [정상] 👤 수동 — 인터뷰 중 프로젝트 유형 자동감지 확인

**사전조건**: TC-003에서 만든 프로젝트가 있음.
**실행 단계**:
1. 목록에서 해당 프로젝트를 클릭해 인터뷰 화면(`/projects/{id}/interview`)에 진입한다.

### TC-005 [정상] 👤 수동 — 인터뷰 진행 + 진행률 바(N/11)

**사전조건**: 인터뷰 화면 진입 상태.
**실행 단계**:
1. 질문에 답변을 입력하고 `전송`(또는 Enter)한다.
2. 몇 개 단계를 반복 진행한다.
3. 좌측 진행률 카드의 숫자·막대를 관찰한다.

**입력값**: 각 질문에 대한 자유 서술 답변(예: 대상 사용자, 핵심 기능 등)
**예상 결과**:
- 답변 전송 시 버튼이 잠깐 `전송 중...`으로 바뀌고, AI의 다음 질문이 이어진다.
- 좌측 레일 진행률 카드에 `{현재} / 11` 숫자와 채워지는 막대가 표시되고, 답변할수록 증가한다.
- 채팅 상단에 `STEP NN` + 단계 제목, 하단 통계 바에 `답변 N개` 등이 갱신된다.

**확인 방법**: 분모가 **11**로 표시되는지(마케팅 문구의 10이 아님), 진행할수록 막대가 차오르는지 확인.
