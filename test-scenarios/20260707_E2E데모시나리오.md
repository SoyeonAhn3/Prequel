### 실행 증거 기록 기준

- 모든 수동 테스트는 결과와 함께 **실행 일시·브라우저·최종 URL·콘솔 오류 유무**를 기록한다.
- 네트워크 동작을 검증하는 테스트는 대상 요청의 **HTTP 상태와 응답 본문**을 기록한다. Playwright 도입 후에는 실패 시 screenshot·trace를 보존한다.
- 크레딧 테스트(TC-012·017·018)는 실행 전후 `users.credits_used`와 프로젝트의 `status`, `interview_credit_charged_at`, `credit_charged_at`을 기록한다. 키·JWT 등 비밀값은 기록하지 않는다.
- 실제 Supabase 테스트 데이터는 기존 사용자 데이터를 수정하지 않고 격리된 일반 사용자·프로젝트로 만들며, 종료 후 삭제하고 잔존 행 0건을 확인한다.

### TC-005 [정상] 👤 수동 — 인터뷰 진행 + 진행률 바(N/11)

**사전조건**: 인터뷰 화면 진입 상태.
**실행 단계**:
1. 질문에 답변을 입력하고 `전송`(또는 Enter)한다.
2. 몇 개 단계를 반복 진행한다.
3. 좌측 진행률 카드의 숫자·막대를 관찰한다.

**입력값**: 각 질문에 대한 자유 서술 답변(예: 대상 사용자, 핵심 기능 등)
**예상 결과**:
- 답변 전송 시 버튼이 잠깐 `전송 중...`으로 바뀌고, AI의 다음 질문이 이어진다.
- 좌측 레일 진행률 카드에 `{현재} / 11` 숫자와 채워지는 막대가 표시되고, 답변할수록 증가한다.
- 채팅 상단에 `STEP NN` + 단계 제목, 하단 통계 바에 `답변 N개` 등이 갱신된다.

**확인 방법**: 분모가 **11**로 표시되는지(마케팅 문구의 10이 아님), 진행할수록 막대가 차오르는지 확인.
