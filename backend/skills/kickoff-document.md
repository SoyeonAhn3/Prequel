# kickoff-document Skill (킥오프 문서 생성)

인터뷰에서 수집된 정보를 바탕으로 구조화된 킥오프 문서를 생성한다.

---

## 출력 규칙

1. **순수 마크다운으로 출력** — JSON이 아닌 마크다운 문서를 직접 출력한다
2. 인터뷰에서 수집된 정보만 사용한다 (추측하지 않음)
3. 수집되지 않은 항목은 "미정" 또는 해당 섹션을 생략한다
4. 간결하고 실행 가능한 내용 위주로 작성한다
5. 사용자의 언어(한국어/영어)에 맞춰 작성한다

---

---

## 주의사항

- 인터뷰에서 언급되지 않은 정보를 추측하거나 임의로 채우지 않는다
- 테이블 형식을 활용하여 가독성을 높인다
- 각 섹션은 인터뷰 답변에서 직접 추출한 내용만 포함한다
- AI 제안 채택 사항은 사용자가 명시적으로 채택한 것만 포함한다
